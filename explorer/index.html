How these records are used

From evidence to post-training

  1. 1. Establish the baseline

    Give Qwen3-8B the same question, first with country prompting, then with dated evidence. Inspect policy correctness and unsupported claims.

    Input: question + optional evidence
    Output: model answer for comparison
  2. 2. Review and train a small LoRA

    Use approved question–evidence–answer examples. The prompt provides context; only the target completion contributes to supervised loss.

    Qwen3-8B · thinking disabled
    TRL prompt/completion · PEFT LoRA
  3. 3. Test what changed

    Use separate event families for evaluation. Compare baseline and adapter on the same questions, including agreement controls and language variants.

    Inspect fidelity, conditions, attribution and invented commitments—not just different wording.

The examples shown here are visible development candidates, not a hidden test set or model outputs. A useful persona preserves supported differences and supported agreement. DPO needs reviewed preference pairs; RL needs validated rewards and trajectories. Neither dataset is prepared here. Continued pretraining is an optional later ablation using cleaned source text.

Format: TRL SFT · adapters: PEFT LoRA · mode: Qwen3 · evidence-conditioned adaptation: RAFT (motivation, not a replication) · behavioral evaluation: CheckList

Why the old view looked Ukraine-only
