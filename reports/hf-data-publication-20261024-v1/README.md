# Private Hugging Face data publication

The sibling JSON receipt binds the private Hub revision, exact file manifest and all remote verification counts. These are the executed publication helpers and small integrity/download checks, preserved for provenance. They are historical scripts with fixed source/audit locations, not an automatic new publication queue.

The complete payload manifest is in the Hub dataset; its SHA-256 is pinned in the receipt. No multi-GB archive was created. Original research files/manifests and older releases were preserved. No model calls or optimizer updates occurred.
