# Evidence and decision register

This register distinguishes **library contracts**, **published findings**, and **our experimental choices**. Papers motivate mechanisms and tests; none establishes the optimal hyperparameters or “perfect” China/Germany personas. Exact seeds, budgets, thresholds and milestone sizes below are hypotheses chosen to make the first experiments cheap and interpretable.

| Decision implemented | Basis and source | Why it fits this project / what remains unproven |
|---|---|---|
| Model country, institution, role and date explicitly | Role-conditioned instruction construction in [RoleLLM](https://aclanthology.org/2024.findings-acl.878/) | We adapt role conditioning to documented institutions. Fictional-character performance is not evidence of national-policy fidelity. |
| Begin with authentic observed answers | Supervised conditional likelihood in [TRL SFT](https://huggingface.co/docs/trl/v0.24.0/en/sft_trainer) | We have real spokesperson targets. Creating imagined beliefs or mixing unrelated ministries would change the target behavior. |
| JSONL conversational `prompt` / `completion`; last answer alone is completion | [TRL dataset formats](https://huggingface.co/docs/trl/v0.24.0/en/dataset_formats) | Matches the trainer's interface; provenance stays in aligned manifests rather than becoming output text. |
| Model-native chat template and EOS | [Transformers chat templates](https://huggingface.co/docs/transformers/v4.57.1/en/chat_templating) | We verify that the rendered prompt is an exact prefix of the full conversation and preserve the assistant terminator. |
| Completion-only loss; earlier assistant responses are context | [TRL completion-only training](https://huggingface.co/docs/trl/v0.24.0/en/sft_trainer#train-on-completion-only) | Avoids supervising journalists, other ministries or repeated prior answers. CPU integration tested with real source examples. |
| Keep complete dialogue history; exclude >8,192-token examples | Context-conditioned SFT; maximum length is a [TRL configuration contract](https://github.com/huggingface/trl/blob/v0.24.0/trl/trainer/sft_config.py) | Full history avoids silently dropping a follow-up's antecedent. 8K is our memory/cost boundary, not an optimal-context result. Report exclusion bias and retain originals. |
| Do not translate the training corpus automatically | Model card's [multilingual support](https://huggingface.co/Qwen/Qwen3-8B) + controlled-experiment reasoning | Translation introduces another model and political-terminology errors. We expose the English/German confound and use common-English diagnostics. This does not solve the training-language imbalance. |
| Start with 250 real examples per country | [LIMA](https://arxiv.org/abs/2305.11206) shows useful alignment can arise from a small curated set in its setting | Motivates testing data quality before spending heavily; it does not show 500 examples are enough for diplomacy. Our 16-step first epoch is only a proof of concept. |
| Equal examples per country without duplicative oversampling | Controlled comparison; measured 7,679:416 eligible imbalance | A project-specific sampling design, not a paper-backed optimal mixture. Report target-token and event shares; equal examples are not equal loss weight. |
| Visit distinct events before extra answers from one event | Repeated observations are dependent; [Dror et al.](https://aclanthology.org/P18-1128/) on matching statistical methods to experimental units | Deterministic round-robin selection is our implementation. It improves event breadth but does not remove within-event correlation. |
| Retain temporal/event-group splits and duplicate families | Standard held-out evaluation and dependence-aware inference | We preserve existing parent/document/family grouping before derivatives. Exact deduplication does not certify semantic or pretraining decontamination. |
| Use Qwen3-8B at a commit SHA | [Publisher model card](https://huggingface.co/Qwen/Qwen3-8B) | User-selected multilingual dense 8.2B model, supported by the pinned Transformers 4.57.6 (publisher minimum 4.51). Tokenizer/config bytes are locked. |
| Disable thinking in every training row and inference prompt | [Qwen3 model card](https://huggingface.co/Qwen/Qwen3-8B#switching-between-thinking-and-non-thinking-mode), [pinned TRL per-row chat-template kwargs](https://github.com/huggingface/trl/blob/v0.24.0/trl/trainer/sft_trainer.py) | User-selected scope. Native empty thinking prefix is context, masked out of loss. Exact input IDs and label boundaries checked through real TRL on a tiny Qwen3 model. No reasoning targets are invented. |
| BF16 LoRA rather than full-model updates | [LoRA](https://arxiv.org/abs/2106.09685) and [PEFT](https://huggingface.co/docs/peft/v0.17.0/en/package_reference/lora) | Small trainable adapters are economical for repeated strategy experiments. Frozen base still requires forward/backward activation computation. |
| Rank 16, alpha 32, dropout .05, all-linear targets | PEFT exposes these [LoRA controls](https://huggingface.co/docs/peft/v0.17.0/en/package_reference/lora) | Values are conventional starting hyperparameters, not proven optimal here. Change rank only after diagnosing capacity/underfitting; keep a matched baseline. |
| Learning rate 1e-4 | [TRL adapter training guidance](https://huggingface.co/docs/trl/v0.24.0/en/sft_trainer#train-adapters-with-peft) | Reasonable adapter starting point. Our 5% warmup, linear decay, AdamW, clipping at 1.0 and one-epoch first run are explicit experimental settings. |
| One process and one full model replica per H100 | [PyTorch DDP](https://docs.pytorch.org/docs/2.8/generated/torch.nn.parallel.DistributedDataParallel.html) | One 8.2B BF16 base fits the intended scale without model sharding. Four processes synchronize adapter gradients; they do not combine VRAM into one model allocation. |
| Microbatch 1, accumulate 8, four GPUs → batch 32 | DDP/Trainer gradient accumulation arithmetic | A memory-first initial configuration. The longest-sequence GPU probe and measured throughput decide whether it should change. |
| Activation checkpointing, SDPA, no packing initially | [Transformers performance](https://huggingface.co/docs/transformers/v4.57.1/en/perf_train_gpu_one), [TRL packing implementation](https://github.com/huggingface/trl/blob/v0.24.0/trl/trainer/sft_trainer.py) | Standard memory/kernel controls. No packing simplifies sample isolation and measured tokens. Later packing needs verified attention boundaries and mask equivalence; speed is not assumed. |
| Start shared, compare separate country adapters later | LoRA enables modular adaptation; factorized experiment on shared versus isolated parameters | The ordering is our cost-control strategy. No cited study proves shared adapters are best for countries. Same country subsets make the comparison interpretable. |
| Prompt-only and same-evidence baselines | Controlled ablation; [RoleLLM](https://aclanthology.org/2024.findings-acl.878/) separates role elicitation and tuning | Distinguishes missing knowledge from adaptation benefit. Retrieval packet and decoding are frozen per case across checkpoints. |
| Matched-English, same-question country pairs, paraphrases and agreement controls | [CheckList](https://aclanthology.org/2020.acl-main.442/) behavioral invariance and directional testing | Our diplomatic adaptation tests supported changes and justified sameness. It does not reward maximizing disagreement or stereotypes. |
| Source-supported claims and separate fidelity/error scores | [FActScore](https://aclanthology.org/2023.emnlp-main.741/) | Adapt its claim-level grounding principle; do not claim to reproduce its automated pipeline or validate political preferences using prose similarity alone. |
| Human/blinded assessment before trusting an automatic judge | [MT-Bench judge study](https://arxiv.org/abs/2306.05685) | LLM judgments can reflect position/verbosity and other biases. No judge-produced scores have been fabricated or used to approve this release. |
| Event-group paired bootstrap, per-country reporting, three final seeds | [Dror et al.](https://aclanthology.org/P18-1128/) + experiment-specific dependence structure | Bootstrap whole event means. 2,000 draws, 95% intervals and 20-group descriptive-only cutoff are chosen settings, not a validated power analysis. Two English issues cannot establish general persona differences. |
| Greedy generation, fixed 256-token cap for initial inspection | Transformers generation API; reproducible controlled decoding | Non-thinking diagnostic choice, not the publisher's recommended temperature 0.7 / top-p 0.8 / top-k 20 sampling. The publisher's warning against greedy generation specifically concerns thinking mode, which is disabled here. Log capped responses and judge both runs with the same budget; test sampling only in a later controlled comparison. |
| Estimate from full sequence tokens, then replace assumptions with measured time | Observed tokenizer volumes + standard throughput accounting | The 800–4,000 tokens/sec node envelope is our unmeasured planning range, **not** a cited performance result. Longer histories cost compute even when their loss is masked. |
| Defer preference optimization until actual error pairs exist | [DPO](https://arxiv.org/abs/2305.18290) | Source-adjudicated preferred/rejected pairs are prerequisites for a meaningful preference objective. Start reference policy at the SFT checkpoint; another country's valid answer is not automatically wrong. |
| Defer domain pretraining and online RL | [Don't Stop Pretraining](https://arxiv.org/abs/2004.10964); no validated diplomatic reward in this project | DAPT can be an ablation for diagnosed domain deficits; its studied gains do not prove this modern persona use case. No reward or new method is invented merely to spend available GPU hours. |
| Leave raw votes, reconstruction speeches and UPR out of the first QA run | Task-specific conditional supervision and observed source limitations in DATA_REPORT.md | Missing proposal text makes votes inadequate as current decision-prediction SFT. Speeches are underdetermined from titles; UPR responses are correlated within a small number of reviews. Preserve these pools for separately designed objectives. |

The register is intentionally explicit where evidence ends. Library support for a parameter does not make its selected value optimal, and a paper demonstrating a mechanism elsewhere is not a guarantee of diplomatic-persona quality.
