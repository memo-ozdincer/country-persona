# What our current training does—and what country deliberation still requires

Research audit, **1 October 2026**. This checkpoint contains analysis and primary-paper acquisition, with **zero new model calls and zero optimizer steps**. The latest measured checkpoint remains [the Gaza checked-plan comparison](AURORA_BENCHMARK_GROUNDED_PLAN_20260930.md). All diagnoses below distinguish observed failures from behaviors we have not tested. Proposed experiments are conditional decisions, not a launch queue.

**The largest gap is a mismatch between the supervised task and the broader behavioral claim.** The latest adapter learns to write a neutral comparative memo from supplied national positions. The goal is for dated country–institution–role agents to apply evidence, defend appropriate constraints, revise when evidence changes and improve collective decisions. A better writer is a useful component; its improvement does not establish those other links. Our evaluations enforce detailed coverage but do not yet test that complete chain on independent, structurally different cases.

The user's bullet-plan idea should be retained. It isolates realization and already helps the base model. We should add a separately identified application task if we want the student to learn evidence selection and policy application; increasing optimization of the existing two memo targets cannot by itself tell us whether that happens.

An unmeasured goal is not evidence that the model necessarily fails at it. Conversely, a known output failure does not reveal whether its cause is memory, evidence selection, imitation, context interference, decoding or the interaction protocol. Those require interventions.

## Locate the failure before choosing the optimizer

The relevant chain is:

`dated sources → application plan → national response → peer revision → aggregation → assessed outcome`

At each boundary, retain the source claims and output so that the same downstream component can receive either the model's intermediate result or a checked substitute. A checked-plan writer comparison isolates realization. A raw-evidence application comparison tests evidence selection/application. A fixed, verified set of national notes tests aggregation. These are different interventions; a gain in one should not be attributed to another.

For example, if a checked UK plan states draft support and the base writes it correctly, the previous UK reversal cannot be used as evidence that the writer still needs to learn that position. If the raw-evidence planner reverses it, supervise or repair that stage. If correct national notes become false consensus only in the final memo, change/evaluate the aggregator. If errors appear only after a partner's assertion, investigate revision/history handling. If a verbose plan loses late items, inspect allocation and obligation tracking before interpreting it as national bias.

This distinction matters in the existing [deliberation implementation](../src/country_persona/deliberation.py): adapters are permitted on national/central stages but the final synthesizer deliberately stays base. That is a useful control for a future national-agent adapter. It does not directly test the latest comparative-memo adapter's intended use, which is closer to the synthesis stage. Both experiments can be valid if separately defined; silently inserting the memo adapter into national roles changes its task contract.

## Supervision that fits the intended behavior

**Keep facts in dated evidence and teach how to use them.** A government, its population and a Reddit community are different targets. Pooling their material as a single country personality would blur the construct. Public statements support declared institutional positions, not hidden national utility. Every application example should identify country, institution, role, date, source scope and whether the target is a historical statement or a checked hypothetical application.

A useful response-only SFT row is:

`input: role/date + permitted source excerpts + proposal + visible discussion history`

`target: supported position + material reason/constraint + feasible amendment or uncertainty + appropriately bounded response to the partner`

The source-informed teacher may use a checked bullet plan privately to construct that target. If the student also receives the completed plan, we are training the writer. If the student must select/apply evidence, its inputs must omit the completed answer and any historical outcome it is supposed to predict. Keep the two task definitions and adapters identifiable. Do not remove legitimate retrieval evidence just to make the task harder.

Prefer paired, controlled examples over more neutral summaries: the same proposal under two documented roles; the same role before/after valid policy evidence; an apparently persuasive peer assertion without supporting evidence; a corrected partner contribution; inadequate evidence requiring uncertainty; and a case where agreement really is supported. Include multiple defensible formulations where appropriate. Source checks should cover the entire target, not only cited sentences.

This teaches evidence-sensitive behavior directly. “Opinionatedness” remains a possible byproduct. We should measure whether responses expose relevant priorities, objections and workable alternatives rather than train for confidence, disagreement, rhetorical intensity or lexical novelty. A country that agrees for a well-supported reason should not be penalized to manufacture diversity.

**Use trajectories only where needed.** If the model handles first responses but follows mistaken peers or retains contradictions, collect its actual histories and supervise the corrected next turn. Clean teacher essays alone may miss these states. SOTOPIA-π supplies a direct precedent for interaction-data SFT; GKD motivates investigating student-distribution mismatch. Our affordable corrected-history variant would not reproduce GKD's teacher-distribution objective.

**DPO and RL remain conditional.** DPO becomes interpretable when a source audit establishes why one of two otherwise comparable responses is preferable, including both justified disagreement and justified agreement. An automatic preference for the teacher or a more assertive voice is inadequate. RL becomes attractive when an environment can verify source/role constraints and joint proposal feasibility without rewarding fabricated agreement or evaluation-specific phrasing. We have not built that reward. No current evidence says either method must precede another useful small SFT test.

## Harder evaluation with interpretable strictness

The [current scorer](../src/country_persona/policy_eval.py) is a strict conjunction over supplied ratings: any unmet item fails; ambiguity can leave a response unresolved. That is useful for integrity and full coverage. It does not automatically make the underlying task difficult or the judgment valid. Requiring every detail can make a largely faithful response fail, while a rubric that omits a material invented claim can miss a serious error.

Preserve the Gaza ratings and unresolved veto item. Decide the explicit/implicit coverage construct for a **future rubric version**, with positive/negative examples, before seeing new outputs. Do not reinterpret an exposed item just to raise the adapter's score. Keep separate measures for material role/position violations, unsupported assertions, required coverage and interaction outcomes; retain the existing strict score alongside them where comparable.

Use claim–source entailment, including polarity, speaker, date and voting stage. An exact quotation can accompany the opposite conclusion. Omission requires checking the whole output; bounded absence means “not supported in this supplied complete statement,” not “this country has no policy.” For applications, predefine admissible options/constraints rather than require the teacher's wording or one unjustifiably unique decision.

OOD should be specified along axes:

- **Event/source family:** hold out the entire meeting, draft, amendments, related statements, translations and generated derivatives. Audit overlap across both benchmarks and training/development material.
- **Structure:** alter a material constraint while preserving surface form; change wording while preserving the constraint. Correct behavior should change only in the first case.
- **Role/time:** separate national capacity from chairmanship and new policy evidence from old. Test uncertainty when the correct institution/date is absent.
- **Task:** distinguish supplied-plan realization, raw-source application and outcome prediction. Improvement in one is not scored as improvement in another.
- **Interaction:** later test new partners, speaking order and information distribution after an initial signal; do not run a full factorial campaign now.

One or two new events can support a development decision, not estimate population-level persona improvement. Event families are the sampling units; 29 content annotations on one event are not 29 independent trials. Historical cases may be in base pretraining. Fresh hypothetical applications can test compositional use of provided constraints, but their targets are declared-policy applications rather than historical prediction labels.

Retain existing benchmarks for comparability and source linkage. They do not supply every construct needed here. The acquired **UNBench** vote test has 6,210 Yes, 209 Abstain and one No out of 6,420; Always-Yes reaches 96.73% accuracy with zero minority recall. This is the UNBench audit, not the separate UNSC-Bench dataset. Use per-class support/recall, balanced accuracy, macro-F1, invalid-output rate and probability scores for prediction; exclude outcome labels from its inputs. Do not invent minority outcomes to balance France/UK/India/Brazil. [Existing audit](EVAL_LEARNING_LOG_20260926.md).

## Multi-agent improvement has a separate burden of proof

The current common-information protocol can test whether peer notes improve source analysis. It cannot by itself establish negotiation skill or private-information integration. It also allows only one revision based on frozen initials, not an unfolding exchange where concessions and revelations change subsequent turns.

A bounded interaction test should give two roles a concrete proposal with source-supported constraints. A peer message is useful when it corrects a claim, supplies missing authorized information, explains a conflict or enables a feasible amendment. Track those changes and their provenance. Keep a valid minority objection even when no agreement is possible; reporting the specific incompatibility is an acceptable outcome when predetermined constraints cannot jointly be satisfied.

Compare peer revision first with self-revision under matched allowances. If useful, compare with independent national responses passed to the same fixed aggregator and a single analyst given the same total accessible information. For distributed-information tasks, the single analyst needs the pooled information control; otherwise peer advantage could simply reflect access to more facts. Record actual generated tokens, input lengths, calls and latency as well as nominal caps. Equal caps alone do not establish equal compute.

Inspect national responses and the final synthesis separately. The fixed aggregator may discard a valid objection even when national agents improve. Conversely, a stronger aggregator could improve the final memo without any changed national behavior. This is why learning national application and training comparative synthesis should remain separate claims.

## The next small decision, and what its result would change

First adjudicate the coverage definition and audit upstream plans where independent review is available. Then prepare **one unexposed issue family with two source-supported contrasting roles**, and reserve a different family untouched. The diagnostic question is whether the saved writer adapter has any useful application transfer beyond a strong base-plus-evidence prompt. This is a transfer diagnostic, because national application differs from its training contract.

A maximum **12-response initial pack** is sufficient for that development question: two roles × base/saved-adapter × three scripted conditions (initial application, unsupported peer pressure, valid evidence update). Freeze the response obligations, permissible alternatives and source links first. Pressure/update prompts use fixed checked histories and identical scripted messages for both weights, so this isolates response behavior; it is not yet an autonomous multi-turn rollout. The two branches differ in the kind of evidence supplied, rather than using pressure as a preceding event in the update branch. Inspect every full response before another action. Twelve is an engineering bound, not a statistical power claim.

| Inspected result | Next justified action |
|---|---|
| Base already handles the material role distinctions, pressure and updates | Move to one controlled interaction case. Do not train solely to create a weight change. |
| Raw-source application fails, while a checked-plan substitute succeeds | Prepare a small source-application SFT release, potentially 20–50 thoroughly checked examples across distinct training families. Teacher plans may be privileged; student inputs must require the intended application. This is a diagnostic-scale starting point, not a proven sample requirement. |
| Both raw-source and checked-plan realization fail | Repair the plan/coverage/invention problem first. More national application labels do not address a broken writer boundary automatically. |
| First responses work, but pressure or revision fails | Supervise corrected next turns on relevant student histories, with valid-update and legitimate-agreement controls. |
| National turns work, final aggregation loses constraints | Evaluate a fixed-note aggregator correction or protocol change before changing national-agent weights. |
| Output judgment remains ambiguous | Resolve the construct/source issue before selecting a winner or increasing optimization. |

Only the selected branch should become the next run. Continue with Qwen3.5-4B on the locked single-GPU Aurora path; compare base/adapter using the same **NVIDIA RTX PRO 6000 Blackwell Server Edition**, model revision, runtime, code and inference protocol. No new multi-GPU setup is needed to answer this question. Training loss or additional steps should not substitute for inspecting held-out behavior. Increase model size within the user's ≤8B scope only if a controlled failure persists after the task/data/measurement boundary has been corrected; present evidence for that choice.

The expected contribution is therefore testable: a small model applies dated institutional constraints more faithfully than its evidence-prompted base, and that gain produces identifiable source-supported benefits in a controlled exchange. Broad “persona change,” more interesting viewpoints and multi-agent gains remain separate, measured hypotheses rather than consequences assumed from fluent text or a successful fit.
