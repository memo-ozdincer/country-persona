# Choose one extra writer review before routing

The earlier leave-family-out fit predicts held bundle rewards from an
empty-record review and three singleton reviews. It trails the
forward-all routing control. Test whether one additional review can
turn model estimates into an actionable choice.

Hold the previous opening policies, request budget, delivery channel,
two inventory laws, reward and leave-family-out regressions fixed.
For each held family variant and each law, choose a single unknown
pair or triple to inspect. Compare the predicted planning-value choice,
the planning-value choice if every candidate could score 70, each fixed
mask, and hindsight selection. Candidate scores used for selection
come only from the ridge estimate or the optimistic value. For each
selected mask reveal its actual archived release score, then select
and plan using only the five reviewed options. Also retain a no-extra
review control and forward all with its earlier singleton prediction.

Aggregate first within event family, then equally across families.
Report gross utility and break-even cost per deployment relative to
forward all and reviewed-only. One extra review is a one-time cost
that can be amortized across deployments. Keep every family result
and record how often each mask is chosen. Enumerating actual candidate
scores gives the one-review hindsight ceiling. This replay uses existing
archived writer outputs and modeled delivery. It adds no reviews,
generations or optimization updates.
