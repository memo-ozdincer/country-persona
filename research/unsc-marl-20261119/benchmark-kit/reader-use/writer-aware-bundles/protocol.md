# Learn which received evidence bundle to forward to the writer

Use complete scored receipt banks containing actual archived final
records. Leave one event family out at a time, keeping renderer variants
and source orders of that family together. The public selector receives
the empty and three singleton release and material labels. It receives
no held pair or triple score. Fit a fixed ridge residual predicting the
change in release score over the best reviewed subset. The learned
features are the standalone scores, count of active sources, and number
of standalone release failures. No model calls or review labels are
added during this comparison.

Compare forwarding every note, selecting the best reviewed sub-bundle,
additive singleton extrapolation, the fitted selector, and an exact
subset ceiling using all labels. Score all incoming masks. Then compose
each selector with the same frozen opening decisions and exact planner
for the selector's estimated reward, using both inventory laws. Replay
the resulting plans against the archived final records. Preserve cost,
material, empty-selection and release outcomes. The result concerns
archived, same-assistant-scored writer banks on exposed cases and
modeled delivery. It tests whether a learned downstream decision
improves coordination when added evidence can reduce final quality.
