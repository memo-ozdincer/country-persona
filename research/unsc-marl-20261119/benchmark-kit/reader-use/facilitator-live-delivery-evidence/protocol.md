# Run the learned third slot through a language channel

Use the frozen fitted action-value weights and the existing public
opening plan. Use one early UNIFIL witness with complementary
Brazil and China sections, one with potentially complete evidence,
and two correlated Myanmar cases in which the learned request and
fixed request differ. The inventory and early loss branches are
chosen before language inference. They include both a learned
advantage and a fixed-script advantage in the typed reference.
They form an execution diagnostic, with no frequency estimate.

Encode each chair request with a fixed English question about a
documentary topic. Never expose the action index in the question.
The model returns one of the shuffled public topic labels or 0 for
silence. The decoder sees the same public catalogue in every arm.
The private desk applies the learned, fixed, or independent routing
table to the heard topic and its own inventory. An invalid decode
becomes silence. The desk's second model call puts the selected
reviewed evidence note on the wire in natural language. It sees
one authorized payload or an explicit empty payload. Accept the
exact note or silence under the same gate for every arm. This
test keeps the previously reviewed note's content fixed.

All three arms have two opening send slots, one optional request
and one final send slot, with the same transport fees. The language
arms share an 8-token decoder cap and an 80-token payload cap.
Every policy uses two logical model calls per episode. Reuse
physically identical requests during batching and record both
counts. The existing independently written records provide a
frozen compiler for every mask. Verify the exact note lineage,
log requested and transmitted cards and charge attempted sends
even if the payload fails the guard. Report source coverage,
guarded score, strict completeness and transport net separately.
This protocol tests live decoding and transmission of authored
English within a structured exchange.
