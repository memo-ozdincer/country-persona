# Preflight the reply interface before routing Resolution 2699

The archived seven-weight router stays frozen. The preflight runs three fictional archival questions about one delegation while giving the writer a source about another. It compares visible questions with source-only writing, then applies the frozen rule to pick an interface. A pass requires the documented actor and literal tag and date, without naming the unrelated actor. The checks assess a narrow interface property and treat even a correct disclaimer naming the unrelated actor conservatively. The probes use neither Haiti source facts nor final-record scores. The renderer gives the highest credit for recording each delegation's position, distinguishing the two abstentions, and preserving the Council's operative authority. ## Results

The frozen preflight checks pass zero of three question-visible probes and two of three source-only probes. The first visible reply correctly says that the named delegation's view is absent from the authorized source. The other two assert that their named delegations made no comment, which the cards cannot establish. The first source-only reply preserves the date and changes its order from “14 May” to “May 14.” The locked literal gate therefore selects independent source-only delivery. The six probes consume 669 input and 199 output tokens, reported separately from simulated routing charges. [Probe responses](final-records.json) · [Frozen preflight decision](results.json)

All four query inputs decode correctly. Only the question-free China reply passes all three documentary criteria. The Ecuador source-only reply loses the stated relationship to a comprehensive response. Every Russia reply changes the source's demand for substantive approval instead of presentation after the fact into a claim that approval should come before the Council receives the proposal. Source isolation prevents the question from supplying the wrong speaker and leaves these completeness and interpretation errors possible. [Exact reply witnesses and reasons](review.json)
