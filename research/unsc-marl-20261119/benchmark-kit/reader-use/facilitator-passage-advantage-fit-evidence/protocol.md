# Fit the value of a question relative to silence

Freeze the adaptive opening agents and responder. Use their greedy maps and public receipt distributions on the 30 existing development banks under both inventory laws. On each legal and reachable question, compute the conditional net value over silence under the declared perfect admission channel and modeled query erasure. Estimate features from the public rubric and fit target values from the receiver-side development reward. Use the three existing chair features, centered against silence, and fit one linear model by exact weighted least squares. Weight each action by the receipt's probability divided by the number of legal questions at that receipt. Keep the full signed differences including penalties for questions that re-send redundant material.

Evaluate on both archived UN cases using the observed admission matrices. Report the frozen learned policy, the fitted advantage policy, declared counterfactual calculation and fixed-team silence. Choose silence when no estimated question value is positive. Report the fixed-team measured-channel optimum as a bound, and report signed regret against the declared calculation separately from measured replay performance. Under a secondary partner intervention apply the same weights to the planner opening maps, with refreshed features and the same responder weights. Neither observed matrix, held rubric vector, nor held action label enters fitting.
