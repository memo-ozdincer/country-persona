# Write live replies and fresh Council records

This run holds the four earlier execution branches and the
actual decoded requests fixed. Their learned, fixed-request and
independent routes share the first two deliveries. The responding
desk rewrites one authorized source in its own words. The chair
then writes a new Council record from the actual note and the
other received documents. The role and access boundaries follow
the audited UNIFIL and Myanmar packets.

The source-direct control changes only what reaches the chair for
the last delivered source. It provides the official-source card
in place of the responding desk's generated note. The same writer
prompt, generation cap and final rubric are used. A repeated live
source is appended alongside its opening copy. The direct control
gets the source once. The pooled solo cases see all source cards.
The live arms each receive the same number of logical calls and
caps. Their actual token usage and source views can differ.
[Locked procedure](protocol.md) ·
[Prior live route and transport costs](../facilitator-live-delivery-evidence/results.json)

Each record is reviewed for exact source attribution,
material coverage, unsupported claims, off-view citations, and
ending and word cap. The release score and the complete 70-point
pass are reported in addition to the material score. The factual
review uses the original source-checked packet. The earlier execution branches were selected
for diagnostic contrasts.

## Results

All ten replies end within the reply budget. Nine pass the
factual-support review, including the correctly empty reply.
The remaining reply makes an unclear claim about the absence of
procedural material while transmitting India’s national statement.
Support and completeness are separate. The China reply preserves
its criticism of the text, its sovereignty position and its desire
for closer communication. It omits China’s support for the mission.

| Four diagnostic branches, summed material points | Live replies | Direct source cards |
| --- | ---: | ---: |
| Learned routing | 77/280 | 98/280 |
| Fixed request script | 77/280 | 91/280 |
| Independent delivery | 84/280 | 84/280 |

In the UNIFIL paired branch, learned and fixed requests deliver
the China note. The live writer earns 21 points and misses the
explicit overlap in support for UNIFIL. The direct writer earns
35 and includes the overlap. It also attributes China's
sovereignty position to Brazil. The live writer contradicts
itself about abstentions. Both fail factual review.
In the Myanmar branch where the presidency card is available,
the learned live record preserves the distinction between
the procedural announcement and the national explanation.
It omits the draft identifier and incorrectly upgrades
humanitarian access from a call to a mandate. The same
modality error appears with the direct card.

Of 16 distinct final generations, 12 hit the 220-token cap.
All four that end still fail factual review. All live,
source-direct and pooled arms therefore earn zero release
points and no strict complete record. The pooled writers
score 35/70 and 49/70 on material before guards. The model
stops before the 175-word limit in the capped outputs. This
budget bottleneck coexists with attribution and authority
errors already present earlier in the text.

The run has 26 actual generations, with 10 replies and 16
finals. The reply stage uses 1,412 input and 323 output tokens.
The final stage uses 6,231 input and 3,444 output tokens.
Counting each reused prompt at every logical use gives 24
live reply and final calls, 12 source-direct final calls and
two pooled final calls. Opening delivery costs and the prior
decoder calls are archived separately. Transport scores from
the frozen compiler remain the reference for delivery performance.

The source-direct control changes the wording the chair receives
and the actual input tokens. It is paired by branch, receipt and
output budget. The review is same-assistant exact-span grading on
two previously exposed event families and four selected branches.
No optimizer updates or evaluation-population estimates are part
of this run.
