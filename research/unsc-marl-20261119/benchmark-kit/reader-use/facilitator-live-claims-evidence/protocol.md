# Bind clauses to evidence before composing the record

Reuse the same live rewrites, source-direct views, pooled views,
and four routed branches from the previous experiment. Leave the
earlier model outputs unchanged. The public part of each record
is rendered from a checked statement of the official sources.
Before adding a delegation clause, ask the frozen model to copy
an exact witness from the specific source the chair received
or answer NONE. Bind the candidate to the source identifier
before inference. Share identical source and claim combinations
across all policy arms. The maximum witness generation is 74
tokens.

A contiguous literal witness is the first admission check.
After that, rate each witness for all details of the claimed
proposition, using the visible passage and recording an exact
span. The semantic-review arm admits only claims with both
checks satisfied. Compare it with literal-only admission to
expose cases where a genuine quote fails to support the inferred
claim. A false literal admission invalidates release on that
receipt. Withhold unknown or rejected claims. The publisher
renders independently admitted claims and adds explicit overlap
or disagreement only when both required sources support it.

Score against the existing 70-point rubrics, including citation
and role constraints. Record a partial released brief with its
actual supported points. Keep strict completeness separate.
The composition is bounded to 175 words and all generated
witnesses, including invalid forms, are preserved. The same
assistant performs exact-span review for this diagnostic.
