# Learn from delivery receipts without a reliability declaration

Freeze the four joint routing choices: independent delivery, the clean seven-weight fit, and the initial action rule with clean or noisy features. Both opening sends remain fixed. At episode start the online controller selects a pair of decentralized chair and responder tables. After the episode it observes only the opening and final receipt masks and the policy it selected. It sees no private cards, rejected reply types, true regime or final reward. Both local policies obey their previous observation restrictions.

Compare a receipt-updated posterior-mean controller with the same controller that devotes every eighth episode to a routing choice expected to reveal the most about the channel. Charge actual message costs for probes and use the same final-record objective for every choice. Both controllers use four authored channel hypotheses and 4% prior reset per episode. All hypotheses grant reliable silent replies. Include fixed independent, fixed clean-trained and oracle-in-menu comparisons. The oracle is a ceiling for the same four candidates under actual score and dynamics. It is unavailable to either controller.

Use 144 episodes, 128 paired replications and one fixed random seed. Evaluate constant clean, constant noisy and clean-to-noisy-to-clean schedules with phase boundaries every 48 episodes. Reuse the four archived documentary banks under authored noise, then the frozen Resolution 2593 question-visible and source-only reply tables. Evaluate both inventory priors. Opening and conditional ending receipt draws are paired across policies using common random numbers. Report accumulated expected net given the selected action in each episode. Also report time spent asking, posterior clean belief, mode separability of the delivered receipt signal, and phase-specific performance. The evaluation conditions are already exposed and use analytic cached dynamics. They test receipt-driven adaptation without a public declaration, rather than fresh language-policy quality.
