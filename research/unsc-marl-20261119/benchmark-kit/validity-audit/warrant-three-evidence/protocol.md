# Three-delegate disclosure with a certified workshop decision

Add a third delegate to the fictional package workshop. Every role has one of four public card types and knows only its own actual card. Each delegate can file one exact grade, followed by at most one targeted request from the chair. The original link loss and charges apply. A package with any zero grade is excluded. Rank eligible packages by lowest grade first, then total grade. Release a recommendation only when every compatible world shares an optimum. Release impasse only when every compatible world has no eligible package. The chair may use the opening policy likelihood to choose a request, while certification uses only the admitted grades.

Fit all three opening policies jointly for 96 exact shared-return updates on 16 generated domains with uniform type priors. Freeze the fitted weights and test the next 12 generated domains under uniform and correlated type priors. Use one generator seed and no selective case removal. Compare with public local lookahead, uniform stochastic sends, exact constant opening slots, and coordinate search over all 81 local action tables for one delegate at a time. The latter starts from both local lookahead and the best constant opening design. Report it as a feasible comparator with training-independent privileged search time, rather than a global optimum. Also report an upper bound in which a central coordinator chooses opening slots with full world information and chooses its query with full world information after observing losses. Even this coordinator must satisfy the same release rule.

Score the chance of recommendation, impasse, unresolved decisions, and communication cost. Compute the follow-up ablation with identical openings and no request. The experiment uses synthetic data and typed authorized reports. It tests learned selection of what to disclose in a larger decision environment.
