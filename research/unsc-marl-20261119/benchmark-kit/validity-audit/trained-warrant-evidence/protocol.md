# Train what evidence delegates send for a warranted package decision

Run a fictional post-meeting UN drafting workshop. Two delegates privately know their grades for three packages. A zero excludes a package. Select the package with the highest worse-off grade and then highest sum, or record impasse if all packages are excluded. A chair releases a decision only when every complete world consistent with the admitted reports shares an acceptable answer. The evidence test includes all publicly possible worlds and never uses the selection of a report as proof of an unseen grade.

Each delegate sends one exact, authorized grade. Each opener can be lost with probability 0.10. The chair can ask for one grade from either delegate. The request and its reply can each be lost with probability 0.10. The responding delegate forwards the requested grade mechanically. The chair optimizes its request over the distribution conditional on the grades it actually saw. It pays 0.05 for a request and 0.10 for a reply attempt conditional on delivery of that request. Opening fees are the same in every arm. No disclosure can change a private grade or confer official authority.

The two opening policies both learn from a shared expected net reward. They act on their own grades and public features only. Fit once for 96 CPU updates on synthetic grade domains and exclude the three named evaluation panels and their transformed versions from the fit. Compare uniform sends, the initial local-lookahead rule, the learned policy, globally optimized constant package disclosures, and exact maximization over every pair of deterministic local opening tables. Verify each held world's winner with an independent rule implementation. Test all six package permutations under uniform and correlated inventory priors. Report certified recommendation, certified impasse, unresolved, costs, request count and the gap to both comparators. This is a controlled decision-process experiment with simulated private values, not a claim about historical votes or generated discussion quality.
