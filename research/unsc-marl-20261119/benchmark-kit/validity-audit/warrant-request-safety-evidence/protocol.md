# Improve requests only when surviving partner policies support the change

Keep the three-delegate public domains, prior, elected grade-only baseline, message budget and certification rule fixed. Each role deterministically discloses one valid grade for every private card type. Enumerate the 81 local disclosure tables per role. A table survives a public history only if each report could have come from at least one compatible card type with its disclosed grade and slot. Missing reports are ordinary independent loss in this model.

For a new receipt mask, each surviving local table implies a set of possible types. Construct all admissible combinations of those sets across roles. Reweight each based on the same public inventory prior. For every candidate request, evaluate the minimum conditional gain over the grade-only request across those combinations. Depart from the baseline only for a strictly positive minimum gain. The publication certificate still checks all compatible grade-card worlds, including worlds that the inferred disclosure tables would make unlikely.

Replay no history, four ordinary histories and 16 histories, using one seeded set of 32 paired histories per condition. Test the two archived domains with model-selected, sender-compiled reports, and the fixed mixed and coordinate teams across all 12 prior workshop domains under both inventory priors. The method is designed after inspection of the exposed language transfer results. Separately replay a convention change from a mixed, valid history team to a coordinate team on the same domains without notifying the chair. This stress case violates the stable deterministic model. Report where the baseline-relative guarantee applies and measure behavior when it does not.
