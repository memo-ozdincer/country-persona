# Learn the workshop inventory prior from partial disclosures

Freeze the preceding workshop rules and both fitted opening weight vectors. The chair knows the public card domains and a stationary inventory distribution exists, but it does not know which distribution describes the current deployment. A calibration episode gives two independent delegates fixed package slots to disclose. Each report experiences the same 10% loss as before. No complete card, true joint type or payoff label enters calibration. Keep the all-world warrant rule fixed regardless of any estimated probability.

Compare uniform planning with an unstructured joint table learned by EM from receipt masks and grades and a Bayesian matching learner that averages a uniform hypothesis and 24 one-to-one grade-card couplings. The matching hypotheses use 60% coupled mass. Test 32 previously unfiltered grade domains with independent inventories, a hidden permuted association at 65% mass, and a mixture of two hidden associations at 65% mass. The latter is outside the single matching model. Use a single seeded dataset with 9, 27 and 81 nested calibration episodes, balanced across nine opening slot pairs. Freeze the seed, menus, estimates and sampling before evaluating. Keep results for every domain and actual mode.

Use the same archived learned local weights for all estimated-prior arms. A policy chooses opening grades and chair requests using its estimated prior. Evaluate those fixed choices using the actual inventory prior. Also report the fixed-opening control, where only the receipt-conditioned request changes with the estimate, and a planner given the true prior, with local opening weights held constant. Subtract deployment request charges. Report calibration episode and attempted-message counts separately. The comparison measures the payoff from learning a shared environmental model, with no new agent-language training and no additional evaluation labels.
