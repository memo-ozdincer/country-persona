## Reproduce the inputs

From the project root, run `PYTHONPATH=src python research/unsc-marl-20261119/crossbench/audit.py /path/to/new-references.json` with the project's PyArrow environment. Compare the result with the frozen [references](references.json). For the role view, run `python research/unsc-marl-20261119/crossbench/packets.py iraq-unami-mandate-review-2023 overlap role-1`. Valid views are `role-1`, `role-2`, `writer`, `analyst` and `judge`. To score a final answer, append the opaque ID and actual answer to the judge packet and use the existing [judge validator](../judge/score.py).

The four audited variants can test whether a deliberation discovers a real overlap without claiming that it negotiated a historical outcome. ## Partial disclosure readout

The [decision ledger](decision_ledger.py) consumes messages with a source ID, role, compatible options and excluded options. It certifies an admissible option only after both roles explicitly support its compatibility. It certifies impasse only when every option has at least one exclusion. A unique verified option requires evidence against all alternatives. Conflicting declarations by the same role invalidate the certificate and retain both message IDs. The environment can check the truth of each claim against the actor's private simulated mandate. The writer's decision ledger receives only public messages.

An independent exhaustive oracle enumerates 6,561 partial disclosure states and 65,536 corresponding hidden menu completions. It checks the verified, blocked and unresolved sets and tests duplicate IDs, malformed messages and contradictions. In the generated Syria turns, the checked readout identifies both case outcomes from either pair of submissions. Each individual submission alone yields unresolved.
