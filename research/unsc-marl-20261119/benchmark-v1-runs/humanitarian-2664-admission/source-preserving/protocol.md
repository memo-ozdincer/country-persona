# Native synthesis over a source-preserving brief

Use the released benchmark's final judge validator and the completed 2664
calibration, including its 150-word cap. Keep the standalone paragraphs from
the existing authored baseline. Add no standalone paragraph for a source that
did not arrive. Ask the same frozen 4B model for an optional comparison of
the delivered adopted-text and national-statement cards. The chair cannot
rewrite the standalone paragraphs in this setup.

Collect five single requests. Include the empty receipt condition, both
one-card deletions, both cards in adopted-text-first order, and both cards in
India-first order. The chair sees the actual delivered evidence in order, has
the same 85-token generation cap for each request, and is asked to return
exactly NONE when fewer than two items support a comparison. It may infer a
relationship from the content. It receives no authored output, marks,
criteria weights, or outcome labels.

For each composition report standalone and combined released /70, credited
comparison, claim guard, exact output, completion and length. Compare native
choice to verbatim-only and the authored ceiling. Missing source claims fail
the guard. Preserve incomplete or invalid native outputs as failures. Replay
the policy that checks both receipts before calling the native chair in
addition to the policy that always calls. Compute leave-one-message-out credit
from these matched outcomes. The partial values establish a cost-free
reference for a later sender policy and are not themselves a learning result.
