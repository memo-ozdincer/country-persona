# Learn the value of recipient actions with unknown opener conventions

Retain the six exposed grade grids, balanced worlds, exact chair
proof and role-bound literal rendering. The calibration library is
the previous high-grade and low-grade opener pair. Stress it with
four stationary held rules. A median opener picks the middle grade.
A veto-conditioned opener picks the lowest grade on cards with a
zero and the highest otherwise. A public-priority opener chooses
the package the public seat grades highest. A mixture independently
chooses one of the two library rules on each turn. Score both the
silent channel and the earlier shared-peer convention. Also test
a median opener that pays to send on every turn in the shared-peer
panel.

The recipient receives only the same archive observations as before.
Fit local action values directly from those receipts. For each
historical own card, received peer message and documented first
chair report, enumerate the three possible own disclosures. The
public proof checker values each possible disclosure under the
declared independent chair link. It uses no private opening card
or realized episode reward. Average those observed values by the
recipient's local state, initialized with two pseudo-observations
from the original partner library or public forecast.

Compare this estimate with the original finite-library posterior,
its no-history counterpart, an original frozen recipient, and the
exact best response to each true partner. If all library rules
assign zero likelihood to a history, return to the equal-library
forecast and use a uniform proof forecast in unsupported current
states. Keep the same first seat, message budget, peer fees and
final renderer across matched arms. History access is unpriced here.
Replay 0, 4, 16, 32 and 128 archived turns. Use one fixed stream of
1,024 simulated histories in each condition, shared by all policies.
Integrate each next-turn decision exactly and report paired
history-sampling standard errors. Exposed case names denote the
simulation contexts, with no claims about actual diplomatic behavior.
