# Cross the writer revision with the existing routing policies

For each law, prior announcement and pair-grade error, obtain the
restricted fixed and robust adaptive policies for the revised score
bank using the earlier unmodified planner. Each planner receives
the empty, singleton and pair grades of its own writer bank, with
the full-receipt score withheld. Then cross those policies and
their opening tables with both banks. Keep the original policy fixed
when testing the revision alone. This separates a native writer
improvement from the change in behavior caused by regrading.

Independently replay stored policies using branch enumeration.
Report documentary release, costs, net against the same-information
fixed policy, probability of full receipt, and UK note delivery.
The primary writer comparison still uses the free-form pair of
identical input conditions.
