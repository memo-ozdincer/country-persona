# Select immutable evidence passages by ID

Present each of the three national sources as a small menu of numbered
verbatim passages. Each role sees its own menu. The menu includes both
material and optional details where the evidence permits. Ask the model
to return IDs in priority order, with no independent local word cap.
Author the public text from numbered source spans. Each span retains its
source offsets. A deterministic renderer admits only selected IDs from
received cards and concatenates them in documentary order. It reserves
public space and applies the 150-word cap globally. It can add the same
scoped comparison as the prior source-bound writer when receipts include
the predeclared mission and host-concern spans of both relevant roles.
The numbered menus, assembly rule and comparison eligibility are human
prepared and frozen before generation. Neither policy gets extra
information or a different renderer. Compare frozen routing, optimized
fixed targeting and silence across the same states and modeled priors
with the same ten criteria. Also score the public-and-first-passages
control and the deterministic all-passages renderer. These controls
measure how much of the result comes from the numbered menus.
