# Source-bound writing for the matched UNIFIL states

Use one public-summary call on the public vote and operative blocks and
one separate call per delegation block. Each delegation call sees its own
source only. Generate a short attributed summary, and ask whether the source
explicitly supports mission continuation and assesses how much the text
addressed host-country concerns. Fix those axes before generation. Validate
citations as exact contiguous source spans. Unsupported or malformed
comparison labels do not enter the record. This structural check is separate
from semantic review of labels and summary prose.

A deterministic renderer uses the same public summary and only the national
summaries allowed by each receipt mask. A comparison line is permitted when
two received roles supply both mission support and differing assessments on
the same host-country issue. State the overlap on mission support and
contrast on accommodating host-country concerns. No combination-level call
can add a new attribution. Use the same 150-word cap and ten frozen
criterion scores. Keep each rejected fragment and six final receipt masks
in the evaluation. Compare the frozen learned route to fixed request and
silence optimized using these scores. The model, settings, opening states and
policy actions remain frozen. Share the same fragments across all arms.
