# Check which states the existing features cannot distinguish

After observing waste and missed attribution in the UNIFIL audit,
group held presentations by the exact input to the frozen
ledger-only head. Count groups that contain both a profitable reply
and a reply better withheld. Any deterministic policy that uses only
these observations must take the same action throughout such a group.
For each group sum realized incremental utility, including the send
cost. Compare choosing the best constant action per group in
hindsight with choosing the exact action per presentation. This bound
uses the held labels after evaluation and is an upper bound on the
feature interface, not a deployable policy.

For diagnosis, repeat grouping with one additional public quantity:
the number of allowed private requirements that remain possible for
each role, and for the queried role how many are consistent with the
locally verified reply. These observations come from the menu and
already visible signs. No fitting is performed in this audit.
