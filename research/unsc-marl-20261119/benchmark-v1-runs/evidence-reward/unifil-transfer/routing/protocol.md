# Choose a question from public signs in the UNIFIL workshop

With the first-stage controller frozen, give the chair a single
opportunity to query any role about any of the four packages or to
stay silent. Assign equal probability to each one-field requirement
consistent with that role's public signs. The chair integrates over
both verified reply signs and assumes the responder can pass. It
sees no actual role card. Charge 0.04 for a question and 0.035 for a
reply, including a lost reply. Use 0.08 and 0.80 as independent
delivery settings, with one possible reply.

Replay all 256 truthful opening subsets in each of the same three
UNIFIL worlds. Compare exact decision-only and exact record-aware
planning, the frozen synthetic-trained value tree on the chair side
with an exact local responder, and the value tree on both sides.
The exact record control uses the same information, public prior
and fees. Compare projected decision, expected normalized record
gain and actual counterfactual contribution after selecting the
question. Check that different eligible worlds producing the same
public signs yield the same chosen question. Both arms retain the
prior one-item attribution proxy. This is a dependent finite audit,
with the historical family already exposed in development.
