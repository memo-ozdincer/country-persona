# Evaluate questions whose value depends on another reply

Reuse the 768 public-opening and world pairs from the UNIFIL
routing audit. Keep the same single-field public prior, final-record
proxy and costs. Give the chair at most two questions and the option
to stop after any response. For a clean fixed partnership, a
delegate answers each authorized question with its verified sign.
Charge for the question and answer even on erasure. Erasure
leaves the public state as it was. Both deliveries are independent.
A sign can be valuable for the next question even when it earns no
immediate score.

Compare one exact question, greedy exact routing with up to two
questions, two-question exact planning, and two-question planning
with the frozen fitted tree predicting delivered increments. The
greedy policy recomputes the best single question after each
answer. All policies see only the same public signs when choosing.
Replay both signs and erasure in planning, with truth used only
for evaluation. As a counterpart swap, execute the exact planner
against a responder that sends only if its own answer immediately
recovers more score than its send fee. Treat an unexpected pass as
absence, and preserve its question cost. This tests whether local
one-step incentives destroy joint planning value.

Enumerate observed evaluation outcomes at 0.08 and 0.80 delivery.
Report both public-planning and realized gains, identify paths
requiring a bridge reply, and record the public evidence for any
witness. This is a typed simulator and final-record proxy, using one
previously exposed historical family and exactly the previous menu.
