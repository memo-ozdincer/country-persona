# Run a frozen writer on the same UNIFIL witness pairs

Keep the four selected before-and-after witness pairs, official sources,
scoring criteria and verified public proof states. Collect eight final
responses from the same frozen Qwen3.5-4B revision, one per state,
with greedy decoding, a 195-word cap and 280 output tokens. No
delegate calls or training occur. Each writer sees only the public
source blocks, role-attributed signed claims, proved disposition
and public lists of compatible one-field requirements per role.
The verified proof and typed candidates come from the delivered
signs. The writer must label inferred or missing positions. Private
truth, grading marks and gold remain evaluator-side.

Compare the model's released points with the deterministic
reference on these cases and isolate which rubric items changed
between matched histories. Keep raw text, errors and all stop
reasons. Inspect all distinct outputs under the same corpus and
evidence scope. These selective witnesses test whether final-text
value tracks public evidence and the record proxy on a new
historical family. They do not estimate overall UNIFIL performance.
