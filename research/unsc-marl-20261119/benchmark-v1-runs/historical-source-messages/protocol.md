# Replace free-text working notes with source selections

Use Myanmar and the Residual Mechanism, both bench orders, and the
peer and independent conditions. Each desk receives the same
assigned source blocks as in the free-writing baseline. It selects
one owned block ID. The peer's second desk sees the first delivered
excerpt; the independent second desk has no peer excerpt. The
transport sends the selected block verbatim under the original
speaker. Invalid IDs produce an empty message. The final chair has
the original public blocks and both selected messages. Its prompt,
word limits and 280-token generation cap stay fixed.

These are frozen greedy Qwen3.5-4B comparisons with an explicit
selection action. No reward model or benchmark key enters a prompt.
Retain the selection call, the delivered source block, and the
generated final. The eight final records are graded under the frozen
rubric in opaque packet order. Compare with the archived prose
condition and show both raw and released coverage. This changes the
intermediate action and payload together. Report inference usage and
delivered words separately. The aim is to test a bounded action space
for later policy optimization.
