# Let the responding model choose a signed claim

Use the two-opening, last-unknown and already-certified public
states. Ask a named delegate about a single package. Show both actors'
public statements and only the responding delegate's private fictional
constraint. The model chooses one token: Y for compatible, N for
incompatible, or P to pass. Exclude a parser or simulator override of
its chosen sign. This is a finite action interface to language
interpretation.

Freeze Qwen3.5-4B and train a reward residual over its captured features
on synthetic workshop families only. The shared certificate reward
and delivery-cost comparison determine utility for every possible
response. Penalize false disclosure and separately record whether a
false disclosure would create a wrong commitment. Compare frozen
Qwen, a vocabulary-bias fit with the same optimizer, the fitted head,
and the best evidence-aware exact role policy. Evaluate both v1 typed
Iraq and Syria worlds with their written mandate and package language.
The test keeps both role orders and records the public state.

The chair's query is enumerated, not chosen or refit in this experiment.
Presentation reuse within each private mandate pair is tracked.
No archived semantic grades or held requirements enter fitting.
