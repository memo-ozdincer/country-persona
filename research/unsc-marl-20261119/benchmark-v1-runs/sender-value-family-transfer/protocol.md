# Learn the marginal value of sending across docket families

Use the existing three documentary environments for Resolutions 2664,
2739 and 2744. Hold each family out from sender value fitting in turn.
Keep the role-bound receiver choices fixed. The sender sees its own
coverage and claim verification, the published reply contract and the
channel conditions and price. It does not see target terminal scores
when choosing. Restrict features to the same declared rubric values and
document tags in each arm that uses them. These are strong local
metadata supplied for the experiment.

For each held family, measure paired released scores in the other two
families under forced opening receipt versus silence. Cross each
source view with whether the return document arrives. Fit two simple
estimators from the same 24 terminal queries. One pools raw score
advantages by whether the sender expects its receipt to enable a
comparison. The other subtracts the known standalone contribution and
learns only the remaining relationship fraction. At deployment weight
the two estimates by return delivery; send when forward delivery times
that expected advantage exceeds price. Compare to a no-relationship
rule, the same full rubric formula without fitting, and the optimized
arrival-only and content-aware references. Report release and cost
as well as total utility.

Evaluate both existing price grids (96 settings each) per family. Check
the old 2739 frozen transfer and repeat after the already measured
objection paraphrase, with and without the split source verifier. Do not
tune the models using those stress results. Replay uses archived terminal
records and verification. This tests calibration transfer under known
scoring components, rather than inference on unseen public records.
