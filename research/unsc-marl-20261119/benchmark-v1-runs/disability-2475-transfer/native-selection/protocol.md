# Select native role passages for the source-bound record

Freeze a role-local menu from the existing Resolution 2475 source
pack. Each desk has one more passage than its message allows. France
can select one of two passages. Russia and the UK can select two of
three. Include relevant alternatives with distinct content rather
than unrelated distractors. The menu supplies authored paraphrases
of traced sources. Keep the same stable passage IDs in normal and
reversed presentations. The actor receives only its own menu and the
generic task, with no preferred choice, truth label or score.

Use the previously tested whole-message likelihood decoder. Score
all allowed arrays of the required size, their permitted orderings
and JSON spellings. Aggregate spelling mass and separately record the
canonical-only choice. Render selected passages verbatim with the
existing authored public lead. Admit the prewritten France–Russia
contrast only when both trusted source IDs are received. Score all
eight receipt masks with the locked rubric and word cap. Compare
normal and reversed presentation, canonical-only, first-in-order
and a full-information authored selection. Audit the grants for
each source rather than trusting the model to supply attribution.

Six source-local invocations use frozen Qwen3.5-4B, with no optimizer
updates. Check source visibility, punctuation and capacity through
the native token trace. Replay the existing routing policies on the
produced score banks. The experiment is an evidence-selection test
on one exposed docket with authored menus and rendering.
