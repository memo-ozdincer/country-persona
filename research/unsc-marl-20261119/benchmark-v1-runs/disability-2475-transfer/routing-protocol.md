# Test forecast transfer on the new score banks

For each generated writer bank, compare the frozen learned pair
correction and halfway additive correction to the nominal forecast
using the same exact adaptive optimizer. Use the three previous
inventory law families, two prior-information settings and three
review offsets. Hold openings, costs, delivery and legal actions
fixed within a bank. Give all three forecasts the same reported
pair grade and withhold the true full-receipt grade. Reuse the
earlier matching fixed rule on the nominal forecast. The informed
oracle receives the true score bank and mixture.

The writer modes each produce an eight-entry bank. The held
scores are used to evaluate the chosen actions. Report predicted
and true pairs, net differences, released points, and quality below
informed silence. Independently dispatch all policy choices. This
is a one-family transfer against previously fixed corrections.
The channel uses modeled inventories and losses.
