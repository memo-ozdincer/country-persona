# Calibrate the composition decision after a writer change

On Resolution 2744, allow the chair to use either the source-only
record or the new writer's comparison. The earlier role verifier
identifies two plausible relationship pairs before any writer scores
are revealed. Allow zero, one or two scalar calibration scores on
those pairs. Treat an unprobed pair as source-only. Keep a comparison
only if its released score exceeds the standalone record after a
0.5-point simulated use fee. Charge one point for each test record.
These fees are sensitivity assumptions in documentary points.

Order the probes from most to least reach under the frozen
compact-trained policy and the two published held priors. Learn an
exact per-pair admission bit for the current writer. Adjust routing
against the resulting safe table using the same receipt observations
as the prior desks. Compare using the frozen desks instead, carrying
old admissions into a changed writer, and re-optimizing arrival-only
against the same release gate and fee. Evaluate the unseen-to-this-fit
topic-guided and generic writer banks as well as compact. Include a
holdout of all six real pairs for checking fallout from wrong
completed records.

The fit consumes archived scalar scores of selected forced probes.
It does not use the unqueried writer scores when deciding. Evaluation
uses all archived scores to verify what the decisions release. This
is a fixed-input deterministic replay on an exposed docket. Utility
before and after amortizing calibration is reported separately.
