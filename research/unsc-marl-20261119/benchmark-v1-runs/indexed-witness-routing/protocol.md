# Select sentence IDs and verify the claim's necessary elements

Reuse all thirteen official views and the one-sentence deletion from the
previous documentary witness test. Split the existing source texts into
numbered sentences. Ask for a single ID or a contiguous range, or NONE.
Resolve the IDs mechanically to at most four source sentences and at most
100 words. Preserve original characters and record the exact offsets.

For every resolved range, run the same zero-threshold, two-label verifier
twice. One arm uses the old source-claim prompt. The other uses that
prompt with a short conjunction of what must be stated: subject,
negotiation and time objection, or a particular appointment, the speaker's
own support, and assent as a condition distinct from consultation. Both
verifiers get the same exact selected span. Compare them with the former
quote and whole-message routes, and an assistant sufficiency review.
Route and score with the same archived record compiler and reply tables.
Count retrieval, semantic failures, and release separately.

This is a paired interface test on the same exposed source views with
a fixed author-supplied claim. It does not require new record writing,
policy updates or changing the released benchmark.
