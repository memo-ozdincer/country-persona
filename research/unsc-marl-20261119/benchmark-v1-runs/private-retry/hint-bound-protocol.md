# Solve the paid one-bit communication envelope

Keep the fixed receipt probabilities, archive payoff tables and cost
of the original experiment. For each public receipt mask, enumerate
all deterministic local functions from the two private signal values
to a bit. A delivered role sends no hint. Enumerate the chair's
optimal retry independently for every message vector using only the
conditional distribution induced by that message vector. Include
hint cost in the objective. Report fees zero, .15 and .30.

These are privileged bounds. The planner knows the real score bank
and link law, including signal reliability. The dispatch still uses
the same observations and one-retry budget. A no-hint bound uses the
same bank, law and action space. Compare the paid communication value
with the gap between the learned team and the exact no-hint policy,
for both archive and transfer. Verify every selected deterministic
policy by the independent simulator. Decompose the gain by initial
receipt mask. Treat the value of free signals and the loss from
unknown joint writer scores as separate ceilings.
