# Make the release guard an explicit checklist item

In the first run, 45 of 46 responses contain exactly as many labels as
there are coverage criteria. The implicit guard has no corresponding
item in the list. This follow-up changes the prompt so the guard and
criteria appear in one numbered list and specifies the exact answer
template length. Preserve all requests' scopes, archived cases, answer
mappings, budget, release gates and decision rules. Measure format
compliance before interpreting semantic review and net outcomes.
The results are an adaptive prompt repair on the same exposed drafts.
