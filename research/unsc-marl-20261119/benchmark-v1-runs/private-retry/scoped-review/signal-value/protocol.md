# Bound the value of reviewer messages before learning dispatch

Freeze the numbered-checklist outputs, all archived grades, and the
existing delivery laws. Enumerate the best finite dispatch policy over
the two equally likely writer orders for every receipt mask. The chair
knows which packets arrived and the published public and singleton
grades. In the main view it also observes the mechanical format flags
for each candidate and can choose any eligible subset. In a second
view, format flags are delivered only with a review. An over-limit
draft stays an objectively zero-point choice.

At each step the chair can select a receipt subset or pay for a single
recorded review reply from an allowed reviewer. The maximum price paid
per individual answer is 0.75 points. Test 0, 0.15 and 0.75. A known
over-limit draft returns a distinct unavailable result and takes no
model call. Costs accrue as modeled calls. Keep exact answer labels and
format, so the ceiling permits any deterministic transformation,
including compact decoding. Compare owner-only, pooled-only and all
messages. A separate exact-grade oracle has the same action slate.
Record whether any gains are available even before a query and which
receipt states hide cooperation value. The optimizer may use all
archived answers to compute this envelope and is unsuitable as a
held-out performance estimate.

Verify each root optimum by an independent argument for two worlds.
A deterministic review that returns the same value in both cases
cannot change the best action. Once a review separates the two cases,
a policy with exact archive knowledge can pick both distinct optima.
The least expensive separator suffices, and randomized queries cannot
exceed the best deterministic choice.
