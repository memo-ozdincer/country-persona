# Ask about a specific relationship between attributed statements

This diagnostic contrasts the archived whole-record release judgment
with a restricted question about relationships between claims. The new
reader answers one yes/no question about whether the draft links
speakers, claims or institutional roles in a way the evidence does not
license. Use the same format and budget for a general one-question
review and a relation-specific review. The pooled reader sees both
sources. Use two answer-letter mappings and require agreement to emit
a release decision. Record both single mappings and all abstentions.

The seven in-limit archival Resolution 2422 drafts are the development
target. Their expected labels come from the archived semantic release
guard. At this scale these grades are provisional. Add six controlled
drafts using two different source families. Each family has an ordinary
accurate draft, a warranted contrast using "By contrast", and an
unsupported contrast using the same phrase. Use the same excerpts for
all versions of a family. The controls are authored and keyed before
the calls. They are checks for the contrast-word shortcut and for
confusing procedural and national capacity.

For the receipt-5 companion replay, publish the archived pair if both
mappings judge it supported and otherwise publish the checked fallback.
Report the exact archive outcomes, the two-message cost, and the best
achievable dispatch from an observed raw label. The replay keeps the
previous public-format optimum on all other receipts to isolate the
effect of opening this one review. The existing optimum is calibrated
with hindsight and the new route is an adaptive diagnostic. All
arguments about useful signal depend on the two observed drafts.

If a reader admits both drafts, its agreement reports give no usable
binary separation in that receipt. If a reader blocks all contrast
phrases, this procedure attributes no credit for identifying which
relationship the evidence supports. Neither kind of result warrants
training a controller from these labels alone.
