# Learn the retry decision where the joint score is unknown

Use the completed priced hint envelope to partition the channel by
public receipt state. When neither role packet has arrived, optimize
hint coding and retry analytically from the public singleton scores
and a single fitting prior that mixes the two link laws equally.
When one role packet has arrived, keep hints silent and fit whether
to retry the missing packet, from exact team reward. When both
have arrived, stop. The hint planner uses the .85 fitting accuracy
under both evaluation conditions. This protects the exact known
singleton guard before policy learning. The true combined score is
available to the learner only as return feedback on earlier banks.

Train a five-feature Bernoulli head for the unknown joint outcome on
one-receipt branches, using the original 200 updates, step and L2.
Use the missed packet's known singleton gain, the received singleton
gain, the baseline score, a zero-release marker on the received score
and an intercept. Keep all episode family splits and record weights.
Deploy greedily and report stochastic behavior. Compare fixed offsets
of minus seven, zero and plus seven points against the same exact
empty-receipt planner, using the shared signal prior. Select one
threshold in the fixed menu on the training families only, report
all controls and report the full-bank paid hint ceiling separately.
The conditional architecture follows inspection of the earlier trials.
Transport is simulated. No model calls or new grading occur.
