# Choose replay actions by how much their receipts can teach

Compare uniform action exploration against a receipt-design policy. Before each exchange the active policy uses the public channel law and the covariance of the twelve cross-role pair features from earlier receipts. Among all sixteen legal two-desk plans, it chooses the largest expected reduction in log determinant of the pair covariance, using known additive coverage to break exact ties. The early card type is still private and only the later desk can condition on a current delivered early card. The sampling policy gets receipt IDs and scores as before. Its information criterion uses receipt IDs. Ties use the docket's known standalone coverage, which can change the explored sequence. No final scores are used to choose experiments. Both methods use the same RNG draws for private availability and link delivery. Report scores during collection, error and deployment return at the established budgets. No hyperparameter search, training changes or new model calls.
