# Explain the below-arrival outcomes by swapping one role at a time

After the held transfer reveals five regressions, keep every frozen
learned decision table except one desk. Given the known inventory
prior and rubric, compute the later desk's best response to the
unchanged third-desk plan. Compute the third desk's best static
response to the unchanged later desk table. Evaluate those swaps
separately. As a small feasibility check, evaluate both orders of
one coordinate update per desk. The coordinator computes the
expected return from the configured rubric and simulated delivery
law. The actors still see only their original observations. This
uses an exact, modeled payoff table for diagnosis. It does not
establish a deployable learned benefit on this docket.
