# Learn a sender that can handle distinct reply policies

Reuse the same documentary payoff tables and observable sender features.
The target changes from a fixed receiver to a mixture of four previously
defined strategies: claim-sensitive, always Fund, always process and
reversed claim-sensitive. The six held profiles include both deterministic
partners and mixtures. A profile gives the probability of the process
reply for each of three receive observations. The receiver is held fixed
within a profile.

Collect the same 128 randomized episodes per docket for two estimators.
Randomize the sender's send action, both transport draws, and the
receiver's reply choice. The pooled estimator observes whether a reply
arrived. The reply-conditioned estimator additionally observes which
reply arrived. Both see final factual score and source coverage and claim
state. Use no unlabeled synthetic counterfactual score in fitting.
Compare the fixed-claim-reader calibration from the previous experiment
as another baseline.

Evaluate exact expected utility on the same 96 held transport settings
per docket for each partner profile. For the reply-conditioned estimator,
test declared partner probabilities and an unknown-profile variant using
eight independent reply probes per receive observation. Probe effort is
reported separately. Give the oracle the actual archival rewards and
declared profile. Deduct the existing constructed forwarding prices.
This is a repeatable stress test of partner change, not a new LLM run,
new historical record, or end-to-end model transfer.
