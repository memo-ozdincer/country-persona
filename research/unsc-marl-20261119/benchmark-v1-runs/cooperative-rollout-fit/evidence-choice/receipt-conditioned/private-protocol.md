# Distinguish a receipt signal from the contents of the received note

The first archived replay chooses the Russian message
deterministically. A receipt-only rule with common knowledge of that
policy could infer the message. In this added test a private draw
gives Russia exactly one available passage, staffing or medical.
Russia sends the available passage. The chair and Peru know the
probability of each inventory but cannot see the draw unless they
receive the note. Test staffing probabilities 0.25, 0.50 and 0.75,
crossed with all four previous independent delivery rates. This is
a fictional availability perturbation of the archived text.

Deploy the frozen adaptive coefficients, the existing fixed rule,
and exact informed decision rules. Compare seeing receipt content,
arrival only and no receipt information. Each oracle sees the
probability law and documentary reward tables but chooses from the
same assigned observation as its comparison. Verify the table-based
results with an independent closed-form expression. Do not retrain
or select weights on these conditions. Report the value of content
and the incremental value of learned weights separately.
