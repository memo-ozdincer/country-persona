# Optimize the shared selection return with imperfect delivery

After the full-receipt study, test independent delivery uncertainty
on the same structured local menus. Sample an advertised receipt
probability for each desk from 0.35, 0.55, 0.75 and 0.95. The
probability is supplied to all arms, and the actual receipt mask
is hidden when messages are chosen. Keep the prior training
seeds, data counts, update count, optimizer, initial weights and
candidate capacities. In the new fit, the shared reward is the
expected released record across actual receipt masks.

For execution, discount the joint bonus hints by the counterpart
receipt probability. Train only the same three global coefficients.
Compare the new fit, the original weights with new signals, the
original full-receipt policy, the existing fixed rules, and an
additional common-scale rule. Select the common-scale parameter
from the synthetic training scenarios using the same team return,
from the grid 0, 0.5, 1, 1.5, 2 and 3. The rule uses advertised
partner priorities with a single multiplier. Compute a centrally
informed expected-return oracle for comparison.

Evaluate 48 separate synthetic cases and the same two archived UN
menus, under four fixed common delivery rates. Verify every true
documentary return with the archived renderer over all eight receipt
masks. Preserve the earlier full-receipt outcomes. All training uses
a simulated channel and authored score features. The UN results are
an exposed case diagnostic. No LLM weights or source text are fitted.
