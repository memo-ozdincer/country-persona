# Learn evidence selection from shared documentary return

Replace the source selector's language likelihood with a small
decentralized categorical policy. Each role chooses one legal
subset of its local menu at the same capacity as the archive.
All roles receive local coverage values and two receiver signals
per option. The first is the expected joint coverage under uniformly
random partners. The second weights the same relation bonuses by
the receiver's announced local-priority forecast for the partner.
The actor never receives another desk's source text, choices, true
reward table, or final record. The coordinator's hints are simulated
or authored, with the same information available to every rule arm.

Generate 96 training and 48 evaluation scenarios from separate
fixed seeds. Each scenario assigns local coverage and up to three
pair requirements. Maximize exact expected team reward through
shared policy gradients, enumerating the 18 legal joint selections.
This is a small CPU multi-agent optimization. It uses team returns
and no optimal-action labels. A frozen zero-weight policy, first in
order, local coverage, uniform-partner value, priority-forecast
value and an informed joint oracle provide controls. The first four
fixed decision rules use the same available information. The oracle
sees the reward table. Freeze all training settings before evaluating.

Apply the unchanged weights to Resolution 2475 and Resolution 2422
with authored local and relation tags derived from their existing
rubrics. Compute true documentary release by calling the archived
renderers and scorers. Test both display directions. The 2475 decoder
archive provides a language-policy reference. Do not use these cases
to fit weights or select checkpoints. The authored priorities make
this an integration test of an evidence allocation policy over a
structured interface. It does not measure automatic extraction,
historical persona learning or transfer to private records.
