# Compile a chair record from public sources and delegate declarations

The Iraq checklist recovered some facts and increased source errors.
Hold the frozen v1.1 cases and rubric fixed. Evaluate a deterministic
chair that copies dated public passages and computes proposal or
impasse from complete public declarations. It preserves the exact
fictional menu and distinguishes it from the historical action.
Use both Iraq orders and both Syria orders for each variant. Iraq
uses archived model replies that were collected in sequence. Syria
uses two independently collected replies from the same raw baseline
episode, so their composition is a parallel replay. Exclude the
duplicated projected-note runs.

Test complete declarations, either declaration missing, a second
incompatible declaration by the same role, and an internally coherent
false declaration. The public chair receives no private mandates,
rubric or target. A separate role-local audit filters the false
declaration using that role's mandate. Record raw and filtered
decisions to expose the trust requirement. Score complete records
against the unchanged final rubric. The chair uses case-specific
public field labels and no gold choices. This is an exposed
structured-protocol replay using archived language calls, with no
fresh generations or training.
